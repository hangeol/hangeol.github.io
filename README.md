# Hangeol Chang — Academic Portfolio

Personal academic homepage for Hangeol Chang, Ph.D. student at the KAIST Kim Jaechul Graduate School of AI.

The same source supports two delivery targets:

- ChatGPT Sites hosts the existing public version.
- GitHub Pages publishes [hangeol.github.io](https://hangeol.github.io/).

Every push to `main` builds and publishes the GitHub Pages version automatically. The portrait, CV, and social preview image live in `public/`.

## Local development

```bash
npm run dev
```

## Validation

```bash
npm run build:pages
```
